# 学生请假与证明办理指南

【演示资料】本文件为毕业设计虚构示例，不代表任何学校的实际规定。实际业务请以所在学校最新通知为准。

## 学生请假
学生因病或因事无法参加教学活动，应提前在学生事务平台提交请假申请，填写请假起止时间、原因及联系方式。病假需上传医疗机构出具的证明，事假需说明具体事由。
请假 1—2 天由辅导员审批，3—7 天由学院审批，超过 7 天由学院审核后报教务部门审批。特殊紧急情况可先联系辅导员，再补办手续。假期结束后需在平台完成销假。

## 在读证明
在读学生可通过教务系统的“证明打印”功能申请在读证明。电子证明通常即时生成，带章纸质证明可持学生证到学院教务办公室领取，办理时间为工作日 09:00—11:30、14:00—16:30。

## 成绩单
中文成绩单可在教务系统自助下载，盖章版本可在自助打印终端打印。英文成绩单需提交申请，示例办理周期为 3 个工作日。办理前请核对姓名、学号和课程成绩是否正确。
